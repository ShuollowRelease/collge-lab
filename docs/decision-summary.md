更新时间：2026-10-06

## 范围与验收口径

- 主要目标平台为 Electron 桌面端，编辑器最小宽度按约 1024px 设计。
- 七项需求按“先完成全部功能，再统一重构 UI”的节奏推进；每个任务完成后执行构建、语法或专项自检。
- 不执行 Git 提交、推送、重置或清理用户已有改动。临时截图、日志和导出验证文件使用后删除。
- 历史聊天记录只用于恢复意图；当前源码、`AGENTS.md` 与本文件决定实际实现。

## 功能决策

1. 自定义布局采用归一化网格数据：行列分隔线、交叉节点偏移、单元格形状、填充模式和撤销/重做均属于 `state.customGrid`。预览与导出继续共用 `paintCollage`，编辑辅助层只存在于 React 预览层。
2. 出图预设按“社交内容、布局、主题、视频 / 播放器”分组，卡片同时显示用途、画幅和会修改的关键参数，点击只应用一个预设补丁。
3. IG 与视频面板的交互状态放入 `state.ui`、`state.igStats`、`state.ytStats` 和播放器元数据；交互改变预览和导出结果，并通过现有设置持久化链保存。
4. 播放器图标继续使用当前 `src/engine/icons.js` 的 Canvas 图标字典；独立 React 播放器使用内联 SVG，补齐播放、音量、循环、随机、上一首、下一首、画中画、剧场和全屏语义。
5. 签名支持五种内置字体、本地字体文件（woff/woff2/ttf/otf）和 PNG/SVG 签名图导入。文本设置留在设置状态，二进制资源以 data URL 形式保存到 IndexedDB，避免把大文件塞进 localStorage。
6. 动效采用 CSS transform/opacity 与有限的 canvas 预览过渡；尊重 `prefers-reduced-motion`，不在导出路径中加入时间相关效果。
7. UI 最终重构继续使用 HeroUI 的 Tabs、Button、Switch、Select、Slider 等基础组件；颜色、间距、圆角和阴影统一从 CSS token 读取。

## 风险控制

- 不引入新依赖；字体和签名导入只接受本地文件，并限制类型与大小。
- localStorage 写入只保存可序列化设置，图片对象和运行时 URL 不写入；恢复失败时回退到默认状态。
- 每阶段先建立可回退的小改动，再运行 `npm run build` 和已有 `tools/verify-*.mjs` 中相关检查。

- 在现有 `customGrid` 下增加 `mode: "freeform"`，保留旧规则网格作为默认兼容路径；旧版设置不需要迁移即可继续打开。
